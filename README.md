# Glasses VR – Product Designer Immersive Experience

This project is a lightweight VR design concept built with **A-Frame** for a product designer workflow.

## Concept
The environment is an explorable immersive world with three core zones:
- **Research Hub** for user goals and problem framing.
- **Prototype Lab** for interaction states and UX flow.
- **Validation Deck** for experiment outcomes and iteration planning.

A central animated artifact represents the active product concept while surrounding interactive 3D forms create a sense of exploration.

## Interaction
- Move with **WASD** or arrow keys.
- Look around with mouse (pointer lock).
- Use gaze cursor to focus on objects in VR-like mode.

## Run locally
Open `index.html` in a browser, or serve via a static server:

```bash
python3 -m http.server 4173
```

Then visit <http://localhost:4173>.
